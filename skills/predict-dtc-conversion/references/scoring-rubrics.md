# S07 Scoring Rubrics

Use 0-100 scores. Label weak evidence as hypothesis.

## Prelaunch Page Requirement Readiness

This is a readiness score: higher means the launch page/PDP requirements are clearer and better supported.

```text
Prelaunch Page Requirement Readiness =
  15% segment/JTBD and use-case clarity
+ 15% competitor/category benchmark coverage
+ 15% previous-generation learning coverage
+ 15% proof asset requirements
+ 10% price/offer framing requirements
+ 10% trust policy requirements
+ 10% CTA/funnel action clarity
+ 10% tracking/event requirements
```

Hard caps:

```text
no owned page yet -> max 69 for conversion diagnosis confidence, but not for planning usefulness
no competitor/category benchmark -> max 59 for page requirement confidence
no previous-generation data -> max 79 for previous-generation learning confidence
no tracking/event plan -> max 69 for launch readiness
```

## Funnel Friction Score

This is a friction score: higher means more friction.

```text
Funnel Friction =
  20% message mismatch
+ 15% proof gap
+ 15% price/value ambiguity
+ 15% trust/risk-reversal gap
+ 10% CTA or form friction
+ 10% checkout/payment/shipping friction
+ 10% mobile/scanability friction
+ 5% tracking/attribution gap
```

## Segment Landing Page Fit

```text
Segment Landing Page Fit =
  25% segment/JTBD match
+ 20% message promise continuity
+ 20% proof and objection handling
+ 15% price/value explanation fit
+ 10% CTA/action fit
+ 10% local language/channel fit
```

## Price Trust Checkout Friction

```text
Price Trust Checkout Friction =
  25% target price shock risk
+ 20% missing value proof
+ 15% weak delivery/return/warranty trust
+ 15% payment, tax, shipping, or stock uncertainty
+ 10% review/Q&A/social proof gap
+ 10% policy or support ambiguity
+ 5% checkout complexity
```

## Tracking Readiness

```text
Tracking Readiness =
  25% conversion event clarity
+ 20% source/medium/campaign attribution readiness
+ 15% funnel-stage event coverage
+ 15% traffic quality filters
+ 10% experiment split or cohort tracking
+ 10% privacy/consent handling
+ 5% reporting ownership
```

Hard caps:

```text
no conversion action defined -> max 49
no tracking context for CVR estimate -> max 59
no page/funnel material -> max 49 for page-level confidence
only AI heuristic judgment -> max 39 for CVR confidence
```

## Experiment Priority

```text
Experiment Priority =
  25% business impact
+ 20% uncertainty reduction
+ 20% decision proximity
+ 15% speed/traffic feasibility
+ 10% measurement clarity
+ 10% risk reduction
```

Hard caps:

```text
no primary metric -> max 59
no decision rule -> max 59
requires traffic volume unavailable before launch -> max 69
```
