# S02 Scoring Rubrics

Use these rubrics to make S02 measurable. Scores are 0-100 unless stated otherwise. Clamp final scores to 0-100.

## JTBD Evidence Strength Score

```text
JTBD Evidence Strength =
  Unique Source Item Count * 0.18
+ Theme Cluster Confidence * 0.15
+ Cross-Source Agreement * 0.15
+ Journey Specificity * 0.12
+ Segment Clarity * 0.12
+ Competitor or Substitute Link * 0.10
+ Local-Language Clarity * 0.08
+ Source Quality and Recency * 0.10
```

Interpretation:

```text
80-100 = strong evidence-backed scenario
60-79  = usable scenario with caveats
40-59  = weak but testable hypothesis
0-39   = data gap or context only
```

## Scenario Priority Score

```text
Scenario Priority Score =
  Pain or Progress Intensity * 0.18
+ Product-Job Fit * 0.14
+ Commercial Weight * 0.12
+ Reachability / Digital Shelf Fit * 0.09
+ WTP or Price Credibility * 0.09
+ Competitive Gap * 0.09
+ Proof Availability * 0.08
+ GTM Moment Leverage * 0.07
+ Earned Growth or Advocacy Potential * 0.04
+ Evidence Strength * 0.10
- Activation or Return Risk * 0.08
- Claim or Compliance Risk * 0.06
```

Interpretation:

```text
75-100 = lead launch scenario
55-74  = useful secondary scenario
35-54  = test or segment-specific scenario
0-34   = do not lead with this scenario
```

Interpretation:


## Scenario Confidence Cap

Cap confidence at:

```text
high
  Evidence strength >= 80 and at least 3 distinct source types support it.

medium
  Evidence strength >= 60 and at least 2 distinct source types support it.

low
  Evidence strength < 60, source types are narrow, or signal is mostly user-provided.

assumption_only
  No direct consumer evidence supports the scenario.
```
