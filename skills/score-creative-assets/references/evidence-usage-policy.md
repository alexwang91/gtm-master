# S05 Evidence Usage Policy

Use this before reading, citing, storing, or rendering copy evidence.

## Evidence Classes

```text
uploaded_private_copy
  Treat as restricted by default. Do not expose raw unpublished copy, scripts, file names, or performance details in public HTML unless approved.

public_copy_example
  Use for category norms and channel conventions. Do not copy creative text or present it as endorsement.

internal_performance_data
  Use only as approved private evidence. Report derived conclusions and confidence, not raw confidential rows, unless approved.

upstream_handoff_evidence
  Prefer evidence IDs from S01-S04 handoffs. Do not reopen full artifacts unless needed.
```

## Public Copy Search

Use public web/MCP search only when:

```text
the user asks for category/competitor copy norms
local channel wording conventions are unknown
copy scoring depends on platform/PDP requirements
the copy references competitor claims that need verification
```

Search targets may include:

```text
official brand sites
retailer and marketplace PDP text
ad transparency libraries when accessible
public YouTube/TikTok/Instagram captions or transcripts when accessible and permitted
local specialist media
public creator post text
platform ad format documentation
```

Respect robots, platform terms, access restrictions, and privacy. If a source cannot be accessed, record the access gap.

## Text Observations

When observing copy:

```text
quote or summarize only the text needed for analysis
separate exact copy observation from strategic interpretation
do not infer visual intent from missing images or layouts
do not infer performance from writing style alone
preserve local-language wording when it affects meaning
```

## HTML Safety

Public HTML should render:

```text
copy IDs or short approved excerpts
scores and revision briefs
claim/proof risk status
data gaps
derived performance interpretation
```

Public HTML should not render:

```text
raw private unpublished copy
raw scripts/transcripts unless approved
raw unpublished performance data
unapproved brand-sensitive strategy
private creator contracts or media rates
restricted consumer data
```
